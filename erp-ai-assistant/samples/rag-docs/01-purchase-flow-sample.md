# 采购业务操作说明（示例）

## 1. 主链路

本系统采购主链路为：

物资请购 → 采购订单 → 到货单 → 采购入库 → 采购发票

说明：
- 物资请购：内部需求，尚未对外下单
- 采购订单：与供应商确认的采购契约
- 到货单：货到确认；与入库分开
- 采购入库：增加库存；未审核时库存常未生效
- 采购发票：与入库/订单匹配后进入应付环节

## 2. 采购订单常见必填

保存采购订单前，至少检查：
- 供应商（未建档通常不能下单）
- 存货编码（本系统不叫物料编码）
- 数量
- 单价（含税/未税以现场配置为准）
- 交货日期
- 仓库（本系统无货位）

## 3. 常见问题

### 3.1 提示请填写必填字段

按页面红字逐项补齐。不要为了过校验去改库存或绕过审核。

### 3.2 采购入库无法审核

优先检查：
1. 当前公司会计期间是否打开
2. 是否正确关联到货单/采购订单
3. 存货编码、仓库、数量是否一致
4. 是否有审核权限

### 3.3 公司隔离

本系统 1 个主公司 + 3 个子公司。跨公司不得串用仓库与单据数据。

## 4. 高风险操作

以下操作必须人工确认，助手不得代执行：
- 直接改库存现存量
- 删除已审核入库单
- 绕过审批
- 期间关闭后强行过账
