# 库存与异常处理（常规 ERP）

## 1. 基本概念

- **仓库**：存货存放组织单位。部分系统还有货位/库位；本教材默认「只有仓库」。
- **库存现存量**：某存货在某仓库的当前结存，属于实时数据。
- **出入库方向**：采购入库增加库存；销售出库/领料出库减少库存。

## 2. 单据与库存生效

常见规则：
1. 录入单据 ≠ 库存已变
2. 审核/过账后库存才生效（有的产品把两步合并）
3. 已过账单据一般禁止直接改原单数量，应走退货、红字、调整单等合规路径

## 3. 常见异常

### 3.1 出库提示库存不足
原因可能包括：现存量确实不足、仓库选错、入库未审核、被其他预留占用。  
处理：先查现存量与在途入库，再决定补货或改单；**不要直接改账改库存数字**。

### 3.2 仓库选错
跨组织/公司选错仓库会导致后续核算与权限问题。常规做法是作废或红冲后重做，而不是私下改历史结存。

### 3.3 盘点差异
通过盘点单调整账实差异，保留审计痕迹。学习要点：调整要留痕，禁止无单据改库。
