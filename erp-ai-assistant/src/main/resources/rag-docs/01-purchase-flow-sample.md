# 采购业务说明（常规 ERP）

## 1. 主链路

常规进销存采购链路常见为：

请购/物资请购 → 采购订单 → 到货/收货 → 采购入库 → 采购发票 →（应付/付款）

本学习项目教材约定简称：

物资请购 → 采购订单 → 到货单 → 采购入库 → 采购发票

要点：
- 请购是内部需求，不是对外合同
- 采购订单是与供应商的订货契约
- 到货确认与入库记账可能分单
- 入库未审核时，库存现存量常常尚未增加
- 发票用于匹配入库并进入应付环节

## 2. 采购订单常见字段

保存采购订单前，业务上通常关注：
- 供应商（未建档通常不可选）
- 存货编码（教材亦称物料/存货编码，本项目统一教「存货编码」）
- 数量、单价、税率
- 交货日期
- 收货仓库

## 3. 常见问题

### 3.1 必填字段未填
按界面提示补齐必填项。不要用改库存、绕过审核的方式“冲过校验”。

### 3.2 入库无法审核
优先检查：会计期间是否打开、是否关联到货/订单、数量与存货是否一致、是否具备审核权限。

### 3.3 货到票未到
许多系统支持暂估入库，后续到票再回冲/调整。具体科目以财务制度为准；学习项目只要求理解“可暂估、须后续处理”。
