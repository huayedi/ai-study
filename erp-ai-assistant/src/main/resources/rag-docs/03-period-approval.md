# 会计期间、凭证与审批（常规 ERP）

## 1. 会计期间

会计期间是允许记账的时间范围。  
期间关闭后，通常不能再对库存/总账类单据过账；需由有权限人员重开期间或做到下期（视制度而定）。

学习要点：
- 业务日期落在已关闭期间 → 审核/过账失败很常见
- 助手不应建议“偷偷改期间标志”这类绕过手段

## 2. 凭证

财务凭证必须借贷平衡。  
不平衡时按序检查：分录金额、方向、自动生成凭证的来源单据是否异常。

## 3. 审批与高风险操作

常规高风险操作（学习项目一律要求人工确认）：
- 删除已审核入库/出库单
- 直接修改库存现存量
- 绕过审批流
- 关闭期间后强行过账
- 无发票依据的付款

## 4. 多组织/多公司

大型实施常有多公司/多账套。  
原则：公司之间主数据与仓存、单据默认隔离，不能串用。  
本教材设定示例：1 个主公司 + 3 个子公司，强调隔离，便于以后练「按范围检索」（仍属学习，不接真实权限系统）。
