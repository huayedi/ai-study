# ERP 最小术语表（通用版）

> 用途：学习与提示词素材。这是**国内进销存/财务 ERP 常见叫法**，不是你们公司私有名词。  
> 请后续把「你们系统实际菜单名/单据名」改到「本系统别名」列。  
> 生效提示词见同目录 `erp-system-prompt.txt`（已嵌入精简版）。

| 术语 | 含义 | 易混点 | 本系统别名（请填写） |
|---|---|---|---|
| 物料 / 物料编码 | 存货主数据及其唯一编号 | 不同于客户编码、供应商编码 | |
| 仓库 / 仓位 | 存货存放地点；仓位是仓库内更细位置 | 有的系统只有仓库没有仓位 | |
| 供应商 | 采购业务相对方主数据 | 未建档通常不能直接下采购订单 | |
| 客户 | 销售业务相对方主数据 | 信用额度属实时数据，不能编造 | |
| 采购申请（请购） | 内部要货需求，尚未对外下单 | 不是采购订单，也不是入库单 | |
| 采购订单（PO） | 向供应商确认的采购契约单据 | 下单≠收货≠应付 | |
| 到货 / 收货 | 货物到达并做收货确认 | 有的系统到货与入库分两步 | |
| 采购入库 | 收货后增加库存的入库单据 | 未审核/未过账时库存常未生效 | |
| 暂估入库 | 货到票未到，先按暂估价入账/入库存 | 后续需回票、调整暂估 | |
| 采购发票 / 回票 | 供应商开票并与入库/订单匹配 | 发票校验失败不能强行付款 | |
| 应付单 | 对供应商的负债确认单据 | 不等于已付款 | |
| 付款单 | 实际付款出纳/资金单据 | 高风险，必须人工确认 | |
| 销售订单 | 客户要货契约 | 不等于出库，也不等于应收 | |
| 销售出库 | 发货出库，减少库存 | 已过账后改原单通常不合规，应走退货/调整流程 | |
| 库存现存量 | 某物料在某仓库的当前可用/结存数量 | **实时数据**，无查询工具不可编造 | |
| 审核 | 业务单据合规确认（常改变单据状态） | 审核≠过账；有的系统合并概念 | |
| 过账 / 记账 | 单据生效并写入库存或总账 | 高风险；期间关闭时会失败 | |
| 凭证 | 财务会计分录单据 | 借贷必须平衡 | |
| 会计期间 | 允许做账的时间区间 | 期间关闭后通常不能再过账 | |
| 组织 / 账套 | 业务归属与账务隔离单元 | 跨组织/账套数据不能随便串 | |
| BOM | 物料清单（用哪些子件组成父件） | 设计 BOM ≠ 生产投料 | |
| 核销 | 往来勾对（如发票与付款、预付与应付） | 反核销/冲销通常有严格权限 | |

## 采购主链路（记忆用）

```text
采购申请 → 采购订单 → 到货/收货 → 采购入库（可暂估）→ 采购发票/回票 → 应付 → 付款
```

## 使用建议

1. 先把上表「本系统别名」列按你们菜单改 10 个高频词。  
2. 改完后，把变更同步进 `erp-system-prompt.txt` 的「术语摘要」段。  
3. 重启应用后再用同一问题对比效果。
