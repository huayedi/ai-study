# ERP 最小术语表（通用版）



| 术语    | 含义                   | 易混点                    | 本系统别名（请填写） |
|-------|----------------------|------------------------|------------|
| 存货编码  | 存货主数据及其唯一编号          | 不同于客户编码、供应商编码          | 存货编码       |
| 仓库    | 存货存放地点               | 本系统只有仓库没有货位            |            |
| 供应商   | 采购业务相对方主数据           | 未建档通常不能直接下采购订单         |            |
| 客户    | 销售业务相对方主数据           | 信用额度属实时数据，不能编造         |            |
| 物资请购  | 内部要货需求，尚未对外下单        | 不是采购订单，也不是入库单          |            |
| 采购订单  | 向供应商确认的采购契约单据        | 下单≠收货≠应付               |            |
| 到货单   | 货物到达并做收货确认           | 有的系统到货与入库分两步           |            |
| 采购入库  | 收货后增加库存的入库单据         | 未审核/未过账时库存常未生效         |            |
| 采购发票  | 供应商开票并与入库/订单匹配       | 发票校验失败不能强行付款           |            |
| 合同审批  | 与客户创建的销售合同契约         | 与客户使用的契约 等同于对外销售订单     |            |
| 销售订单  | 销售订单内部员工查看           | 不等于出库，也不等于应收           |            |
| 销售出库  | 发货出库，减少库存            | 已过账后改原单通常不合规，应走退货/调整流程 |            |
| 库存现存量 | 某物料在某仓库的当前可用/结存数量    | **实时数据**，无查询工具不可编造     |            |
| 审核    | 业务单据合规确认（常改变单据状态）    | 审核≠过账；有的系统合并概念         |            |
| 凭证    | 财务会计分录单据             | 借贷必须平衡                 |            |
| 会计期间  | 允许做账的时间区间            | 期间关闭后通常不能再过账           |            |
| 公司    | 本系统由4个公司使用1个主公司3个子公司 | 4个公司之间数据不能串要隔离开        |            |
| BOM   | 物料清单（用哪些子件组成父件）      | 设计 BOM ≠ 生产投料          |            |

## 采购主链路（记忆用）

```text
采购申请 → 采购订单 → 到货单 → 采购入库→ 采购发票
```
